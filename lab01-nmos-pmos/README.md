# Lab 01 — NMOS & PMOS Characterization

## Objective

Study the basic electrical behavior of NMOS and PMOS transistors using SKY130 devices in Xschem and ngspice.

## Topics

- DC operating point
- I–V characteristics
- Threshold behavior
- Transconductance `gm`
- Output conductance `gds`
- Output resistance `ro = 1/gds`
- MOSFET regions of operation
